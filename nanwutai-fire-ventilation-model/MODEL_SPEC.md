# 模型规范

## 1. 坐标与空间边界

- `x=0`：最终选定不利方向火灾洞的上游洞口；`x` 沿目标纵向风正方向。
- `y`：从行车洞断面参考线向横向；断面原点必须随竣工图说明。
- `z=0`：路面设计高程；`z` 竖直向上。
- 火源中心：`x_fire=L/2`。研究洞长度未由竣工图核定前不得生成工况。
- 最终FDS域：完整火灾洞、全部横通道、每个横通道对应的安全洞局部短段。

## 2. 参数状态与生成门禁

每个可配置参数包含：

```json
{
  "value": null,
  "unit": "m",
  "source": "待竣工图",
  "status": "MISSING",
  "required_for_generation": true
}
```

- `VERIFIED`：有可追溯的图纸、运营资料、适用条文或批准的建模依据。
- `ASSUMED`：仅用于讨论或占位，不得进入南五台正式工况。
- `MISSING`：尚无值。
- 任一 `required_for_generation=true` 的记录为空或非 `VERIFIED` 时，生成器必须失败。

## 3. 火灾与风速矩阵

| ID | 物理含义 | 当前状态 |
|---|---|---|
| F1 / Q1 | 小型客车完整设计火灾 | 参数缺失 |
| F2 / Q2 | 客车或中型货车完整设计火灾 | 参数缺失 |
| F3 / Q3 | 普通重型货车完整设计火灾 | 参数缺失 |

每档必须同时给出峰值HRR、相对起火时刻的增长曲线、燃料、燃烧热、烟产率、CO产率、车辆阻塞体和燃烧面。组间结论称为“车型设计火灾情景差异”。

粗筛风速从 `0 m/s` 起，以 `0.25 m/s` 递增，直至捕获三档火灾各自的回流抑制转折速度 `u*_q`。五档共同核心风速按下式生成：

```text
u_low  = 0.75 * min(u*_q)
u_high = 1.25 * max(u*_q)
V1...V5 = [u_low, u_low+Δu, ..., u_high]
```

五点等间隔并四舍五入到 `0.1 m/s`；若取整造成重复，按 `0.1 m/s` 向上修正以保持严格递增。零风速属于粗筛基线，不自动进入15组核心工况。

## 4. FDS输出合同

每个横通道入口至少设置：

- 呼吸带 `z=1.8 m` 的左、中、右三个测点：温度、烟尘能见度、CO体积分数；
- 覆盖有效净高的竖向测点列：温度和烟尘能见度；
- 一条 `LAYER HEIGHT` 积分设备，并以竖向剖面交叉检查；
- 拱顶下方测点列：能见度，用于可复现地识别上游烟气前锋与回流长度；
- 供Pathfinder顺序耦合使用的温度、CO、O2、CO2及烟尘能见度空间输出（具体FDS输出形式在软件版本核对后确认）。

FDS模板只规定输入结构和必要输出意图。未经实际FDS解析，不声称模板语法已通过验证。

## 5. ASET、RSET与选速算法

对于横通道 `k`，各指标在任一横向呼吸带测点连续越限10 s时记为该指标失效；ASET为温度、能见度、CO和烟气层高度四者最早失效时刻。阈值为空时禁止计算。

若模拟结束仍未越限，报告 `ASET > T_end` 并标记右删失。只有当以 `T_end` 作为保守下界仍满足安全判据时，右删失记录才可用于判定合格。

Pathfinder每个FDS工况使用30个随机种子。有效横通道的RSET取实际使用者完成通过时间的最近秩95百分位；无人使用标记为 `UNUSED`。

```text
margin_s = ASET_s - RSET_s
ratio    = ASET_s / RSET_s
pass     = margin_s >= 60 and ratio >= 1.5
```

按风速升序，首个使F1、F2、F3全部有效横通道均合格的共同风速为推荐值；没有合格档时输出“当前范围无可行风速”。

## 6. 输入资料到位后的检查点

1. 根据两洞纵坡、洞口和自然风条件选择更不利方向，并记录排除另一方向的依据。
2. 复核长度、断面面积、水力直径、纵坡、横通道及防火门。
3. 检查火源与横通道、洞口、设备及网格边界无冲突。
4. 网格独立性至少采用粗、中、细三级；关键ASET和回流长度变化不超过10%。
5. 通风空载工况的断面平均风速与目标值偏差不超过5%；实际HRR曲线与输入目标偏差不超过5%。
6. Pathfinder自由行走时间与手算偏差不超过5%，并验证出口关闭、改道和人员守恒。
