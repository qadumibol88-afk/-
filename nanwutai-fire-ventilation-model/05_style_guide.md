# Style guide

- Language: 中文为主，FDS/Pathfinder字段保留官方英文。
- Target reader: 隧道火灾与人员疏散研究人员。
- Tone: engineering-feasibility / scientific-question-driven / conservative
- Terminology: 固定使用“车型设计火灾情景”“顺序耦合”“有效横通道”“右删失”“最低稳健合格风速”。
- Forbidden expressions: “已验证”“完全安全”“最佳风速”“真实还原”“风速越高越安全”，除非对应证据和判据已满足。
- Numerical style: SI单位；数值与单位间留空格；风速保留1位小数；时间保留至1 s；浓度明确ppm或体积分数。
- Source status: `VERIFIED`表示有可追溯工程或规范依据，`ASSUMED`表示研究占位，`MISSING`表示缺失且可能阻塞。
- Citation style: 文本采用可点击来源链接；参数文件保存来源名称与URL或工程文件定位。
